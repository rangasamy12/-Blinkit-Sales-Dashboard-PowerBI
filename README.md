# Blinkit Sales Dashboard - Power BI

## 📊 Overview
Analyzed Blinkit (India's Last Minute App) sales data - 8.5K+ products, 1.20M total sales across 10 outlet types.

## 🔍 Key Insights
- **Total Sales:** 1.20M | **Avg Sales:** 141 | **Items:** 9K | **Rating:** 3.92
- **Top Performer:** Supermarket Type1 - 7.87M sales (65% of total)
- **Location:** Tier 3 outlets give 100% sales vs Tier 1 - 71.3%
- **Year:** 2018 established outlets peaked at 204K sales
- **Fat Content:** Regular items (776K) sell 82% more than Low Fat (425K)
- **Item Type:** Household items highest avg sales (149)

## 📈 Dashboard Features
- KPI Cards with total sales, avg sales, items, rating
- Slicers for Outlet Location Type, Outlet Size, Item Type
- Donut charts for Fat Content & Outlet Size
- Bar chart for Item Type performance
- Funnel for Outlet Location, Line chart for Establishment Year trend

## 🛠️ Tools Used
- Power BI Desktop
- DAX Measures
- Data Cleaning & Modeling
